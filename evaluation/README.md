# Rowflow AI Evaluation

Rowflow 서비스의 AI 응답 품질을 평가하기 위한 테스트 코드 및 결과 저장소입니다.

## 1. 평가 개요

- **평가 대상:** Rowflow AI 서비스의 5개 주요 기능
- **기준 생성 모델:** GPT-4o mini
- **자동 평가 모델:** GPT-4o mini (LLM-as-a-Judge)
- **테스트 사례:** 기능별 8개, 총 40개
- **평가 방식:** 자동 응답 수집, LLM Judge 평가, 사람 검토

### 평가 대상 기능

| 기능 | 테스트 ID | 주요 평가 내용 |
|---|---|---|
| 소재 추출 | M01~M08 | 원문 충실성, 핵심 정보 추출, 주제 분류, 근거 문장 |
| 후속 질문 | Q01~Q08 | 맥락 관련성, 단일 질문 여부, 사용자 답변 충실성 |
| 글쓰기 제안 | S01~S08 | 소재 연결 타당성, 원문 충실성, 제안 방향 |
| 에세이 생성 | E01~E08 | 원문 충실성, 구성, 문체, 분량 |
| 에세이 재생성 | R01~R08 | 사용자 수정 사항 반영, 원문 충실성, 문체, 분량 |

평가 지표는 테스트 사례별 목적에 따라 선택적으로 적용했습니다.

## 2. 평가 진행 과정

### 1차 평가: 초기 품질 진단

GPT-4o mini를 대상으로 40개 테스트 사례를 실행하여 주요 오류와 개선 필요 사항을 확인했습니다.

### 2차 평가: 프롬프트 개선 후 재검증

1차 평가에서 발견한 오류를 바탕으로 프롬프트를 개선한 후, 동일한 테스트 사례를 사용하여 결과를 비교했습니다.

### 추가 모델 비교: 진행 예정

GPT-5.4 등 새로운 생성 모델을 대상으로 동일한 입력과 평가 기준을 적용하여 응답 품질을 비교할 예정입니다.

## 3. 평가 코드 구성

| 파일 | 설명 |
|---|---|
| `material_runner.py` | 소재 추출 테스트 |
| `question_runner.py` | 후속 질문 테스트 |
| `proposal_runner.py` | 글쓰기 제안 테스트 |
| `essay_runner.py` | 에세이 생성 테스트 |
| `retouch_runner.py` | 에세이 재생성 테스트 |
| `*_cases.json` | 기능별 테스트 입력 및 평가 기준 |

## 4. 평가 결과

```text
evaluation/
├── README.md
├── material_runner.py
├── question_runner.py
├── proposal_runner.py
├── essay_runner.py
├── retouch_runner.py
├── *_cases.json
├── results/
│   ├── round1/
│   └── round2/
└── reports/
    └── 1차, 2차 평가 비교.xlsx
```

- `results/round1/`: 1차 평가 최종 결과
- `results/round2/`: 2차 평가 최종 결과
- `reports/`: 평가 결과 비교 및 분석 자료

## 5. 평가 방법 및 한계

각 테스트 사례의 목적에 따라 관련 평가 지표를 선택적으로 적용했습니다.

통과율은 **실제 평가에 적용한 기준별 통과 건수 / 전체 평가 기준 건수 × 100**으로 산정했습니다.

자동 평가 결과는 사람 검토를 통해 확인했으며, 필요한 경우 판정을 수정하거나 추가 오류를 기록했습니다.

검수 과정에서 추가로 발견한 항목은 공식 통과율과 구분하여 기록했습니다.

본 평가에는 다음과 같은 한계가 있습니다.

- 모든 사례에 모든 품질 지표를 적용하지 않았습니다.
- 기능별 8개 사례로 구성된 소규모 테스트입니다.
- LLM Judge의 판정에는 오류가 발생할 수 있습니다.
- 평가 통과율은 서비스의 전체 품질을 대표하는 절대적인 성능 점수가 아닙니다.

상세 내용은 `reports/1차, 2차 평가 비교.xlsx`의 **「평가 방법 및 한계」** 시트를 참고하세요.

## 6. 향후 평가 계획

GPT-5.4 등 신규 생성 모델을 대상으로 동일한 테스트 사례와 평가 기준을 적용하고, 기존 GPT-4o mini와 응답 품질을 비교할 예정입니다.

비교 시 원문 충실성, 지시 준수, 한국어 표현의 자연스러움 등 주요 품질 요소를 확인합니다.
