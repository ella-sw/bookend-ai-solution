# Rowflow AI Evaluation

Rowflow 서비스의 **LLM 응답 품질 평가, 모델 비교, 프롬프트 개선 실험 및 최종 모델 선정 근거**를 기록한 자료입니다. **글쓰기 제안을 포함한 5개 기능**을 평가하고, 동일한 5개 기능을 최종 서비스 범위로 관리합니다.

> **최종 선정 모델**  
> - **GPT-5.4:** 후속 질문 생성 · 소재 추출 · 글쓰기 제안  
> - **Claude Sonnet 5:** 에세이 생성 · 에세이 재생성  
>
> **모델 선정 근거**는 기능별 지정 평가 항목의 통과 결과입니다. 응답속도와 비용은 별도 운영 지표로 다룹니다.  
> **최종 적용 프롬프트:** 개발팀은 직접 사용해 본 결과를 바탕으로 5개 기능 모두에 GPT-4o mini 2차 실험의 기능별 프롬프트(V2)를 적용했습니다.

## 1. 평가 개요

| 항목 | 내용 |
|---|---|
| 평가 및 최종 서비스 범위 | 5개 기능(글쓰기 제안 포함) × 기능별 8개 사례 = 40개 사례 |
| 최초 모델 비교 | 3종 모델, 4개 실험 조건, 공통 지정 판정 105건 |
| 비교 모델 | GPT-4o mini, GPT-5.4, Claude Sonnet 5 |
| 기존 실험 조건 | GPT-4o mini V1·V2, GPT-5.4 V2, Claude Sonnet 5 V2 |
| 추가 개선 실험 | Claude Sonnet 5 V3(1차 개선)·V4(2차 개선): 에세이 생성·재생성 16개 사례 |
| 평가 절차 | 동일한 테스트 사례로 모델별 응답 수집 → LLM 예비 판정 → 평가자가 입력·기대 동작·응답을 대조해 최종 판정 → Opik에 결과 등록 및 비교 |

### 평가 대상 5개 기능

| 기능 | 사례 ID | 주요 평가 내용 | 최종 서비스 |
|---|---|---|---|
| 후속 질문 생성 | `Q01`–`Q08` | 맥락 관련성, 질문 간결성, 사용자 답변 충실성 | **포함** |
| 소재 추출 | `M01`–`M08` | 원문 충실성, 핵심 정보 추출, 주제 분류, 근거 문장 | **포함** |
| **글쓰기 제안** | `S01`–`S08` | 소재 연결 타당성, 소재 충실성, 작성 방향 구체화 | **포함** |
| 에세이 생성 | `E01`–`E08` | 원문 충실성, 구성·연결성, 문체, 분량 | **포함** |
| 에세이 재생성 | `R01`–`R08` | 사용자 수정 반영, 원문 충실성, 문체, 분량 | **포함** |

평가 지표는 사례별 목적에 맞춰 **선택적으로 지정**했습니다. 미지정 지표는 통과로 간주하지 않으며 통과율의 분모는 사례 수가 아니라 **실제 지정된 평가 판정 건수**입니다.

| 최종 서비스 기능 | 선정 모델 | 기존 모델 비교 실험의 기능별 성능 |
|---|---|---:|
| 후속 질문 생성 | **GPT-5.4** | **17/17 (100.0%)** |
| 소재 추출 | **GPT-5.4** | **16/16 (100.0%)** |
| **글쓰기 제안** | **GPT-5.4** | **16/16 (100.0%)** |
| 에세이 생성 | **Claude Sonnet 5** | **22/31 (71.0%)** |
| 에세이 재생성 | **Claude Sonnet 5** | **17/25 (68.0%)** |

- **품질 근거:** 동일한 테스트 사례와 공통 지정 판정 기준으로 기능별 강점을 비교했습니다. 표의 수치는 **기존 V2 조건 모델 비교 실험** 결과입니다.
- **운영 지표**로 응답속도와 토큰 비용을 구분했습니다. 모델별 동일 조건 측정값은 후속 검증 대상으로 남겼습니다.
- **참고용 조합 점수:** 선택된 기능별 결과를 단순 합산하면 88/105 (83.8%)입니다. 이는 *각 모델의 기존 개별 평가 결과를 합산한 값*이며 **최종 통합 서비스에서 새롭게 실측한 통과율이 아닙니다.**
- **최종 프롬프트 선정:** 최종 서비스의 5개 기능에는 모두 GPT-4o mini 2차 실험에서 사용한 기능별 프롬프트(V2)를 적용했습니다. V3와 V4는 에세이 생성·재생성의 품질 변화를 비교하기 위한 실험용 프롬프트입니다.

**글쓰기 제안이 포함된 5개 기능, 40개 사례**에서 4개 실험이 공통으로 평가한 **105개 지정 판정**을 비교했습니다. 기존 보고서와 동일한 범위입니다.

| 실험 | 통과 / 지정 판정 | 통과율 |
|---|---:|---:|
| GPT-4o mini V1 | 73/105 | 69.5% |
| GPT-4o mini V2 | 76/105 | 72.4% |
| GPT-5.4 V2 | 80/105 | 76.2% |
| Claude Sonnet 5 V2 | **83/105** | **79.0%** |

### 글쓰기 제안 기능의 모델별 결과

글쓰기 제안 역시 최종 서비스에 포함된 평가 대상입니다. 해당 기능의 지정 판정은 모델마다 **16건**입니다.

| 모델 실험 | 통과 / 지정 판정 | 통과율 |
|---|---:|---:|
| GPT-4o mini V1 | 10/16 | 62.5% |
| GPT-4o mini V2 | 14/16 | 87.5% |
| **GPT-5.4 V2** | **16/16** | **100.0%** |
| Claude Sonnet 5 V2 | 14/16 | 87.5% |

기능별 평가 결과에 따라 후속 질문·소재 추출·글쓰기 제안에는 GPT-5.4를, 에세이 생성·재생성에는 Claude Sonnet 5를 배정했습니다.

## 4. Claude Sonnet 5 프롬프트 개선 실험

5개 기능 중 **에세이 생성·재생성 2개 기능**에 대해 동일한 16개 사례(`E01`–`E08`, `R01`–`R08`)로 추가 실험을 진행했습니다. **V3 = 1차 개선안**, **V4 = 2차 개선안**입니다. 다른 3개 기능(후속 질문·소재 추출·글쓰기 제안)은 이 추가 실험 대상이 아닙니다.

### 4-1. 기존 지정 지표 비교 — 56개 판정

| 실험 | 에세이 생성 (31건) | 에세이 재생성 (25건) | 합계 (56건) |
|---|---:|---:|---:|
| Sonnet 5 V2 (기존 모델 비교) | 22/31 (71.0%) | 17/25 (68.0%) | **39/56 (69.6%)** |
| Sonnet 5 V3 (1차 개선) | 21/31 (67.7%) | 16/25 (64.0%) | **37/56 (66.1%)** |
| Sonnet 5 V4 (2차 개선) | 21/31 (67.7%) | 13/25 (52.0%) | **34/56 (60.7%)** |

기존에 각 사례에 지정된 평가 판정만 집계한 결과입니다. **추가 심층 평가는 56건에 합산하지 않았습니다.**

### 4-2. V3·V4 심층 평가 — 각 지표별 16개 사례

V3와 V4 모두 동일한 16개 사례에서 원문 충실성과 분량 조건 준수를 확인했습니다. 두 지표는 최초 지정 여부와 관계없이 각 사례에 모두 적용했습니다.

| 심층 평가 항목 | V3 (1차 개선) | V4 (2차 개선) |
|---|---:|---:|
| 원문 충실성 | **8/16 (50.0%)** | **4/16 (25.0%)** |
| 분량 조건 준수 | **1/16 (6.3%)** | **6/16 (37.5%)** |
| 두 조건 동시 충족 | **0/16** | **1/16** |

**주요 관찰**

- **분량 개선:** V4에서 요구 분량을 충족한 사례가 **1건 → 6건**으로 증가했습니다. 원문 충실성과 분량을 동시에 충족한 사례도 1건 확인됐습니다.
- **원문 충실성 저하:** V3 대비 V4에서 충실성 통과 사례는 **8건 → 4건**으로 감소했습니다. 글을 늘리는 과정에서 원문에 없는 행동·경험·감정을 추가한 응답이 관찰됐습니다.
- **문체 일치성:** 기존 지정 판정 기준으로 V3의 문체 조건 준수는 15/15 (100.0%)였으나 V4에서는 12/15 (80.0%)로 하락했습니다. 특히 에세이 재생성 사례 `R01`·`R05`·`R07`에서 문체 조건 실패가 확인됐습니다.
- **원문 복사에 따른 원문 충실성 통과:** V3의 `E04`·`E05`·`E06`에서는 AI가 입력 원문을 거의 그대로 반환했습니다. 원문에 없는 사실이나 감정을 추가하지 않았으므로 원문 충실성 평가에서는 통과했지만 에세이 생성에 필요한 자연스러운 재구성은 충분히 이루어지지 않았습니다. 반면 V4에서는 원문을 재구성하는 과정에서 제공되지 않은 내용이 추가되어 원문 충실성 평가에 실패했습니다. 이는 **원문 충실성 통과가 반드시 에세이 생성 품질의 충족을 의미하지는 않는다**는 점을 보여줍니다.
- **분량 집계:** 생성 본문의 공백·문장부호는 포함하고 줄바꿈 문자(`\n`)는 제외했습니다. `input_tokens`, `output_tokens`는 글자 수가 아닙니다. V3의 R03은 원본의 분량 판정이 비어 있어 본문 163자를 단문 기준(300~500자)에 대조해 실패로 집계했습니다.

**해석:** V4는 분량 준수 측면에서 성과가 있었지만 원문 충실성과 문체 일치성을 함께 확보하지 못해 **기존 지정 지표 종합 통과율은 하락**했습니다. 프롬프트 이외의 입력·후처리 조건도 달랐다면 변화를 프롬프트 수정만의 독립적인 효과로 볼 수 없습니다. 또한 V2에는 16개 사례 전부에 같은 심층 평가를 적용하지 않았으므로 **V2의 심층 통과율을 V3·V4와 직접 비교하지 않습니다.**

### 4-3. 최종 프롬프트 선정 및 실사용 판단

기존 지정 판정 기준으로 Sonnet 5의 에세이 생성·재생성 통과율은 V2 69.6%(39/56), V3 66.1%(37/56), V4 60.7%(34/56)로, V2가 가장 높은 결과를 보였습니다.

개발팀의 실사용 검토에서도 V2 프롬프트를 적용한 결과물의 체감 품질이 더 우수하다고 판단하여 최종 서비스에 V2를 적용했습니다.

다만 V3·V4 실험에서는 원문 충실성과 분량 준수 사이의 상충관계가 확인됐으며 평가 지표와 실사용 체감 품질을 함께 고려해야 한다는 과제가 남았습니다.

개발팀의 실사용 검토는 정형화된 사용자 선호도 실험이 아니므로 V2가 실제 사용자 집단에서 더 높은 만족도를 보인다고 일반화할 수는 없습니다.

## 5. 평가 코드 및 산출물

주요 경로는 `evaluation/` 디렉터리를 기준으로 표기했습니다. 저장소에 실제로 포함된 파일과 일치하는지 최종 배포 전에 확인해야 합니다.

| 위치 | 용도 |
|---|---|
| `question_runner.py`, `material_runner.py`, `proposal_runner.py` | 후속 질문·소재 추출·**글쓰기 제안** 응답 수집 및 평가 |
| `essay_runner.py`, `retouch_runner.py` | 에세이 생성·재생성 응답 수집 및 LLM-as-a-Judge 예비 평가 |
| 기능별 테스트 사례 JSON (`*_cases.json` 등) | 입력 사례, 기대 동작, 지정 평가 기준 |
| `essay_runner/results/`, `retouch_runner/results/` | 실행 시 생성되는 응답 로그 및 평가 결과 |
| `reports/` | 모델 비교 보고서와 프롬프트 개선 분석 자료(실제 파일 배치 확인 필요) |
| `opik/sonnet5_final_experiments.json` | 사람 검토 완료된 Sonnet 5 V3·V4 결과 데이터 |
| `opik/upload_sonnet5_final_fixed.py` | Opik V3·V4 재등록용 스크립트 |

자동 평가의 중간 결과와 사람이 최종 검토한 확정 판정은 별도로 관리합니다. `.env`와 API 키 등 비밀값은 GitHub에 업로드하지 않습니다.

## 6. Opik 실험 기록

- **프로젝트:** `Rowflow-LLM-Evaluation`
- **데이터셋:** `Rowflow-Evaluation-40` — **5개 기능 전체 40개 사례(글쓰기 제안 8개 포함)**
- **기존 4개 실험:** `GPT4o-mini-V1`, `GPT4o-mini-V2`, `GPT5.4-V2`, `Sonnet5-V2`
- **추가 실험:** `Sonnet5-V3`(1차 개선), `Sonnet5-V4`(2차 개선)
- **V3·V4 저장 단위:** 각 16개 사례, 기존 지정 지표 56건, 심층 원문 충실성 16건 + 분량 준수 16건

V3·V4는 모델을 새로 실행한 Opik 실험이 아니라 **기존 생성 응답과 사람의 최종 검토 판정을 등록한 이력**입니다. 따라서 Opik의 `Duration (avg.) = 0s`, `Cost per trace = -`는 실제 모델 호출의 응답시간·토큰 비용을 나타내지 않습니다.

보고서의 전체 통과율은 통과 판정 수를 전체 지정 판정 수로 나누어 계산했습니다. 초기 모델 비교는 **5개 기능·105개 판정**, V3·V4 추가 실험은 **2개 기능·56개 지정 판정 및 별도 심층 평가**이므로 각 집계 범위를 구분해야 합니다.

## 7. 평가 방법 및 한계

1. **선택적 평가 지표:** 사례별로 필요한 지표를 지정했으며, 평가하지 않은 지표를 통과로 간주하지 않습니다.
2. **집계 단위:** `105`(5개 기능)와 `56`(에세이 생성·재생성 2개 기능)은 평가 지표 종류가 아닌 **실제 지정 판정 건수**입니다.
3. **소규모 테스트:** 기능별 8개 사례 결과를 실제 서비스 전체의 일반적인 성공률로 해석할 수 없습니다.
4. **Judge의 한계**가 있어 평가자가 원문·기대 동작·응답을 직접 대조하고 최종 판정을 확정했습니다. GPT-4o mini V1·V2 실험에서는 GPT-4o mini가 예비 판정을 맡았습니다.
5. **초기 비교 조건:** GPT-4o mini V1·V2 평가에서 프롬프트 이외 입력 처리 조건의 차이가 개입했을 가능성을 배제할 수 없습니다.
6. **원문 충실성 평가의 한계:** 원문을 그대로 반환해도 원문 충실성 평가에서는 통과할 수 있으므로 해당 지표만으로 에세이 생성 품질을 충분히 판단하기 어렵습니다. 향후에는 **원문 사실 보존 여부와 자연스러운 에세이 재구성 품질을 별도 지표로 평가**할 필요가 있습니다. 또한 글의 확장 과정에서 근거 없는 행동·경험·감정이 추가되는 문제는 해결되지 않았습니다.
7. **운영 지표**인 비용과 응답속도는 실제 실행 기록에서 확인해야 합니다. Opik에 사후 등록한 값만으로는 이를 검증하기 어렵습니다.
8. **실서비스 설정:** 개발팀은 실사용 검토 결과를 바탕으로 최종 서비스의 5개 기능 모두에 GPT-4o mini 2차 실험에서 사용한 기능별 프롬프트(V2)를 적용하기로 결정했습니다. Claude Sonnet 5의 V3(1차 개선)·V4(2차 개선)는 품질 개선 효과를 검토하기 위한 추가 실험으로 최종 서비스에는 적용하지 않았습니다.
9. **평가 결과와 실사용 판단:** 에세이 생성·재생성의 기존 지정 판정 통과율은 V2 69.6%(39/56), V3 66.1%(37/56), V4 60.7%(34/56)로 V2가 가장 높았습니다. 개발팀의 실사용 검토에서도 V2의 체감 품질이 더 낫다고 판단하여 최종 프롬프트로 선택했습니다. 다만 실사용 검토는 정형화된 사용자 선호도 평가가 아니므로 향후 사용자 선호도 평가를 통해 체감 품질을 추가 검증할 필요가 있습니다.

## 8. 후속 개선 과제

- 원문과 생성 결과 사이의 **사실 일치 여부를 검증**하는 절차 마련
