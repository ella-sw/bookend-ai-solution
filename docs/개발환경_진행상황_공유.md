## 2. 한 일 (순서대로)

### ① 저장소 받기

```bash
cd /c/yeardreamschool6th/Final
git clone https://github.com/ella-sw/bookend-ai-solution.git
cd bookend-ai-solution
```

- 저장소에는 원래 `README.md`, `LICENSE`, `ERD.md`(개발자 B 초안)만 있었음
- `git clone`이 `bookend-ai-solution` 하위 폴더를 자동으로 만듦

### ② 도구 버전 확인

```bash
node -v        # v24.17.0
git --version  # 2.54.0.windows.1
```

- Next.js 공식 최소 요구 버전은 **Node 20.9 이상** → v24는 문제없음
- 학교 컴퓨터도 Node 24로 맞출 예정

### ③ 작업 브랜치 만들기

```bash
git checkout -b feat/web-setup
```

- main에 바로 올리지 않고 브랜치에서 작업

### ④ 기획 문서 넣기

```bash
mkdir docs
```

- `docs/`에 넣은 파일:
  - `Rowflow_요구사항정의서_소재추가_v7.xlsx`
  - `Rowflow_UI설계서_소재추가_v7.pptx`
  - `Rowflow_ERD_소재추가_v7.pdf`
  - `v6_이후_수정대기목록.md`
- 목적: VS Code의 Claude와 팀원이 같은 기준 문서를 보게 하려고

### ⑤ Next.js 프로젝트 만들기 (`web/` 폴더)

```bash
npx create-next-app@latest web --typescript --app --eslint --tailwind --src-dir --import-alias "@/*"
```

- 선택: TypeScript, App Router, ESLint, Tailwind CSS, `src/` 폴더, `@/*` 경로 별칭
- Turbopack: 기본값(Yes) 사용
- 가상환경은 따로 만들지 않음 (Node는 프로젝트별 `node_modules`로 자동 분리)

### ⑥ 실행 확인

```bash
cd web
npm run dev
```

- 결과: `Next.js 16.4.6 (Turbopack)`, `Ready in 1321ms`, `GET / 200`
- 브라우저 `http://localhost:3000`에서 Next.js 기본 화면 확인 → **성공**
- 터미널의 "Turbopack has seen frequent file updates…" 안내는 설치 직후 파일 정리 중이라는 뜻이라 무시함
- 확인 후 `Ctrl + C`로 서버 종료

### ⑦ 줄바꿈 통일 (`.gitattributes`)

`git add .` 때 "LF will be replaced by CRLF" 경고가 나옴. 팀에 Mac 사용자가 있어서 줄바꿈을 LF로 통일함.

```bash
cd ..
echo "* text=auto eol=lf" > .gitattributes
git add .gitattributes
git add --renormalize .
```

### ⑧ GitHub에 올리기

```bash
git status       # docs/, web/ 확인, node_modules는 없음(정상)
```

## 5. 집·학교 오가며 작업하는 규칙

| 언제 | 명령어 |
|---|---|
| 작업 시작 | `git status` → 현재 브랜치·미커밋 변경 확인 → `git pull --ff-only` |
| 작업 끝 (매일, 컴퓨터 옮기기 전) | `git add .` → `git commit -m "내용"` → `git push` |
| 다른 컴퓨터에서 처음 | `git clone …` → `git checkout (작업 브랜치)` → `cd web` → **`npm ci`** |
| 다른 컴퓨터에서 받은 뒤 `package-lock.json`이 바뀐 날 | `cd web` → **`npm ci`** (잠금 파일 그대로 설치) |
| 패키지를 새로 추가·변경할 때 | `npm install (패키지)` → `package.json`과 `package-lock.json`을 **함께 커밋** |

- `node_modules`와 `.env.local`(Supabase 키 등)은 GitHub에 올리지 않음
- 학교 공용 컴퓨터면 작업 후 GitHub·Claude 로그인 정리
